# SALVENR website

This is the customer-facing SALVENR Curing Controller website.

## GitHub Pages

The existing `CNAME` file has been preserved as `salvenr.com`.

1. Back up the current GitHub repository.
2. Replace the repository root files with the contents of this folder.
3. Commit and push to `main`.
4. In GitHub: Settings → Pages and keep the current branch/root deployment.
5. The `CNAME` file keeps the custom domain configured.

## Android APK

The website button points to:
`https://github.com/SalveneR/salvenr/releases/latest/download/SALVENR.apk`

Publish a GitHub Release with a file named exactly `SALVENR.apk` to activate it.

## Demo

The embedded HMI is intentionally a sales simulation. It demonstrates the operator experience without requiring physical hardware.
